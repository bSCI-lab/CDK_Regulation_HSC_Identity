# Modulation of transcriptional cyclin-dependent kinase activity preserves human hematopoietic stem cell identity

This repository contains the computational analysis scripts and supplementary tables associated with the study **"Modulation of transcriptional cyclin-dependent kinase activity preserves human hematopoietic stem cell identity."**

The repository is intended to support transparency, reproducibility, and reuse of the computational analyses presented in the manuscript.

## Overview

The repository includes computational workflows and analysis scripts covering the following sequencing approaches:

- **ATAC-seq:** Chromatin accessibility analysis.
- **Bulk RNA-seq:** Gene expression analysis.
- **Single-cell RNA-seq (scRNA-seq):** Single-cell transcriptomic analysis.
- **ChIP-seq:** Chromatin immunoprecipitation sequencing analysis.
- **Supplementary tables:** Scripts and supporting files associated with the supplementary analyses and tables.

## Repository structure

The repository is organized by sequencing modality and analysis type. The directory structure and documentation will be updated as the workflows are consolidated.
